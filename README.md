# Unscathed

This project was created because of my previous repository: multi-source-project

One of the websites in that project, I was only able to extract data from page 1

I couldn't go further than page 1 because the URL of the website wasn't changing when I changed the website to Page 2 in my browser

This happened because server was using dynamic content loading with the help of javascript. This technique is known as AJAX(Asynchronous Javascript And XML) 

And the tool I was using for extraction is beautifulSoup which can not run JavaScript

So, In this project I used Playwright - the browser automation tool to solve the extraction problem, which I couldn't do it before with beautifulsoup.
